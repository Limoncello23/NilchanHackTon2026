# 🏰 Routine Dungeon

> Turn your tasks into damage.

## 🎮 Concept

Your routine is the dungeon.
Your tasks are your attacks.

Complete tasks → deal damage → defeat the boss.

## 🛠 Tech Stack

- Go
- PostgreSQL
- Docker
- REST API
- OpenAPI
